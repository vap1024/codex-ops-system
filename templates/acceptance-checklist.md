## Required checks against disk

- [ ] Read the frozen brief and confirm its revision or hash.
- [ ] Inspect each delivered file in the actual local folder.
- [ ] Compare file list and hashes or revision with the audited artifact set.
- [ ] Read the independent claim-to-source audit, findings, and limitations.
- [ ] Rerun each required command on these same files and save actual results.
- [ ] Confirm all required claims are verified and required checks pass.
- [ ] Resolve owner decisions and record them in the goal's decision log.
- [ ] Request another audit for any artifact changed since the recorded audit.
